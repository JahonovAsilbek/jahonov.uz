Men haqimda

Men Toshkent, Oʻzbekistonda yashovchi mobil dasturchiman. Fintech, raqamli bank, e-commerce va ad-tech sohalarida production mobil ilovalar yaratishda 5 yildan ortiq amaliy tajribaga egaman.

Asosan Kotlin va Jetpack Compose bilan ishlayman: multi-modul arxitektura (MVVM / MVI), type-safe Jetpack Navigation va dependency injection (Koin / Hilt). Shuningdek, Kotlin Multiplatform va Compose Multiplatform yordamida kross-platforma ilovalar yarataman hamda Flutter va React Native ilovalarida ishlatiladigan Android va iOS SDKlarini chiqarganman.

Funksiyalarni boshidan oxirigacha oʻzim olib boraman — arxitektura va UIdan tortib unit / UI testlar, CI/CD va Google Playʼga relizgacha. 100K+ yuklab olishga ega ilovalarni chiqarganman, production bank ilovalarida katta redizayn va arxitektura migratsiyalariga rahbarlik qilganman.

Shuningdek, Claude Code bilan AI yordamida dasturlash workflowʼlarini quraman — custom skillʼlar, multi-agent code review va har bir pushʼda ishlaydigan avtomatik sifat nazorati.

Hozirda Mikrokreditbankda Android dasturchi boʻlib ishlayman. U yerda Mavrid ilovasining toʻliq redizayniga hamda uning XML viewʼlardan Jetpack Compose va multi-modul arxitekturaga oʻtkazilishiga rahbarlik qildim, bankning Compose dizayn-tizim kutubxonasini yaratdim va Kotlin Multiplatformʼdagi Mavrid Kids ilovasini chiqardim.
